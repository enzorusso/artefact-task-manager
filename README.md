# TaskManager

## Description
Technical challenge developed for the [Artefact](https://www.artefact.com/br/) recruitment process. A full-stack task management application built with Next.js 15, React, TypeScript, and tRPC, featuring type-safe CRUD operations, in-memory data management, server-side rendering (SSR), form validation, and infinite scrolling.
